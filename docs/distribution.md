sidebar: development

Install from the eventual public source tag with
`uv add "orcapen-sc-pdk @ git+https://github.com/NCUPHY-LTLab/orcapen-sc-pdk.git@v1.0.0"`.
Its distribution name is `orcapen-sc-pdk` and Python import name is
`orcapen_sc_pdk`. See [Install & Get Started](getting-started.md) for a working
activation example.

Contributors should start with [Contributing](developing-features.md); site
authors should use [Documentation & Website](docs-publishing.md).
