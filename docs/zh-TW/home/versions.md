## 模擬資料快照（Data Snapshot）

模擬資料採用獨立的 `data-YYYY.MM.DD-rN` 版號。[data-2026.11.01-r1 資料快照](https://github.com/NCUPHY-LTLab/orcapen-sc-pdk/releases/tag/data-2026.11.01-r1)僅含四個 SimplePad 案例，各次執行保留原本的 PDK、SCGSim 與求解器（Solver）版本。

此預覽尚非已發布的版號文件快照。安裝時請使用[散布與安裝](../distribution.md)所列的固定原始碼版本。
