點選站名旁的版本選單，可選擇文件版本。本版文件對應 OrcaPen SC PDK **1.0.0**。

| 版本 | 安裝來源 | 文件 |
| --- | --- | --- |
| 1.0.0 | 來源標籤 `v1.0.0` 與相同版本的 GitHub Release 附件 | 目前版本 |

安裝套件請見[散布與安裝](../distribution.md)；取得模擬輸入與結果請見[模擬案例與下載](../simulation/recorded-cases.qmd)。

版本選單只列出實際發布的文件快照（Snapshot）。未來新版取代目前網站時，這一版會保存在 `/v1.0.0/`。歷史模擬仍使用各自記錄的 PDK、SCGSim 與求解器（Solver）版本；把資料包放入新版 OrcaPen Release，不會改變原本的模型。
